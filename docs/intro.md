# DB is Middleware — 과목별 아카이브

> **"DB는 미들웨어이다."** — 2020년대에도 현역인 정처기 교재의 한 구절

이 아카이브는 **정보처리기사 시험**을 준비하면서 마주친,
- 시대착오적이거나
- 사실과 다르거나
- 실무와 완전히 동떨어졌거나
- 그냥 말이 너무 애매한

서술들을 시험용 암기와 실무용 이해로 나눠 다시 읽는 공간입니다.

## 어떻게 정리되어 있나

정처기 5개 과목에 대응해 폴더가 나뉩니다.

1. **소프트웨어 설계**
2. **소프트웨어 개발**
3. **데이터베이스 구축**
4. **프로그래밍 언어 활용**
5. **정보시스템 구축관리**

여기에 별도 섹션으로 **이미지 저장소**를 둡니다. 교재의 작은 그림만으로 감이 오지 않는 UML, DFD, DD 같은 시각 예제를 모아두는 곳입니다.

## 과목별 아카이브와 이미지 저장소의 차이

| 구분 | 역할 | 들어가는 글 |
| --- | --- | --- |
| 과목별 아카이브 | 시험 과목 기준으로 다시 찾아보기 위한 질문형 정리 공간 | 특정 단원에서 헷갈린 용어, 교재 문장 해석, 암기 포인트, 개념 비교 |
| 이미지 저장소 | 그림으로 보는 예제만 따로 모아두는 공간 | 순차 다이어그램, 클래스 다이어그램, 유스케이스 다이어그램처럼 교재 예제만으로 부족한 시각 자료 |

예를 들어 `요구사항 분석 용어 디버깅`처럼 공부하면서 던진 질문과 답변은 **과목별 아카이브**에 둡니다.

반대로 `UML 다이어그램 예제 모음`처럼 같은 상황을 여러 그림으로 비교하는 글은 **이미지 저장소**에 둡니다. 시험 범위에 속하더라도, 목적이 “개념 설명”보다 “그림 감각 만들기”이면 이미지 저장소가 더 잘 맞습니다.

짧게 말하면:

```text
과목별 아카이브 = 질문과 개념 정리
이미지 저장소 = 그림 예제와 표기법 감각
```

## 이 사이트가 하지 않는 것

- 정처기 무용론
- 특정 교재·저자·기관에 대한 인신공격
- "내가 봤을 때 이상하니까 틀렸다" 식의 근거 없는 주장
