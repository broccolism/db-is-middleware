# DB is Middleware — 과목별 아카이브

> **"DB는 미들웨어이다."** — 2020년대에도 현역인 정처기 교재의 한 구절

이 아카이브는 **정보처리기사 시험**을 준비하면서 마주친,
- 시대착오적이거나
- 사실과 다르거나
- 실무와 완전히 동떨어진

서술들을 현직 개발자 관점으로 **팩트체크**하고 모아둔 공간입니다.

## 어떻게 정리되어 있나

정처기 5개 과목에 대응해 폴더가 나뉩니다.

1. **소프트웨어 설계**
2. **소프트웨어 개발**
3. **데이터베이스 구축**
4. **프로그래밍 언어 활용**
5. **정보시스템 구축관리**

태그로 **심각도**(WTF / Outdated / Nitpick)와 **영역**(db / network / architecture 등)을 크로스필터할 수 있습니다.

## 과목별 아카이브와 팩트체크 연재의 차이

이 사이트에는 같은 글감이 두 방식으로 정리될 수 있습니다.

| 구분 | 역할 | 들어가는 글 |
| --- | --- | --- |
| 과목별 아카이브 | 시험 과목 기준으로 다시 찾아보기 위한 참조 공간 | 특정 단원에서 헷갈린 용어, 교재 문장 해석, 암기 포인트, 개념 비교 |
| 팩트체크 연재 | 발견한 문제를 시간 순서대로 읽는 공개 글 | 하나의 이상한 문장을 잡고 배경, 실무 맥락, 시험 대응법까지 풀어쓴 긴 글 |

예를 들어 `요구사항 분석 용어 디버깅`처럼 여러 질문을 모아 단원별로 정리한 글은 **과목별 아카이브**에 둡니다.

반대로 `DB는 미들웨어다?`처럼 한 문장 자체가 오래된 분류나 실무 오해를 만든 경우는 **팩트체크 연재**로도 발행하고, 과목별 아카이브에는 찾아가기 쉬운 버전을 함께 둡니다.

짧게 말하면:

```text
과목별 아카이브 = 시험 범위별 정리 노트
팩트체크 연재 = 시간순 공개 글 / 읽는 글
```

## 이 사이트가 하지 않는 것

- 정처기 무용론
- 특정 교재·저자·기관에 대한 인신공격
- "내가 봤을 때 이상하니까 틀렸다" 식의 근거 없는 주장
