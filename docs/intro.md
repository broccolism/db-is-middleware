# DB is Middleware — 과목별 아카이브

> **"DB는 미들웨어이다."** — 2020년대에도 현역인 정처기 교재의 한 구절

이 아카이브는 **정보처리기사 시험**을 준비하면서 마주친,
- 시대착오적이거나
- 사실과 다르거나
- 실무와 완전히 동떨어진

서술들을 현직 개발자 관점으로 **팩트체크**하고 모아둔 공간입니다.

## 어떻게 정리되어 있나

정처기 5개 과목에 대응해 폴더가 나뉩니다.

1. **소프트웨어 설계**
2. **소프트웨어 개발**
3. **데이터베이스 구축**
4. **프로그래밍 언어 활용**
5. **정보시스템 구축관리**

태그로 **심각도**(WTF / Outdated / Nitpick)와 **영역**(db / network / architecture 등)을 크로스필터할 수 있습니다.

## 이 사이트가 하지 않는 것

- 정처기 무용론
- 특정 교재·저자·기관에 대한 인신공격
- "내가 봤을 때 이상하니까 틀렸다" 식의 근거 없는 주장
