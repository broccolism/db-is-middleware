# DB is Middleware

> "DBMS는 대표적인 미들웨어의 하나이다." — 2020년대에도 현역인 정처기 수험서의 한 구절

**정보처리기사 시험**을 준비하면서 발견한
- 시대착오적이거나
- 사실과 다르거나
- 실무와 동떨어졌거나
- 설명이 너무 애매한

서술을 시험용 암기와 실무용 이해로 나눠 다시 읽는 오픈 아카이브입니다.

사이트: <https://broccolism.github.io/db-is-middleware/>

## 글 구조

이 저장소에는 두 종류의 글이 있습니다.

- **과목별 아카이브**: 정처기 5개 과목 기준으로 다시 찾아보기 위한 질문형 정리 노트
- **이미지 저장소**: 교재 그림만으로 감이 오지 않는 다이어그램과 표기법 예제

과목별 아카이브 글은 보통 다음 흐름을 따릅니다.

1. 질문이 생긴 교재 표현
2. 시험장에서 필요한 정답 감각
3. 실제 개념을 이해하기 위한 설명
4. 헷갈리기 쉬운 관계나 예외

이미지 저장소 글은 같은 예제를 여러 그림으로 비교하면서, 표기법보다 “무엇을 보려고 그리는 그림인가”에 초점을 둡니다.

## 이 레포가 하지 않는 일

- 정처기 무용론
- 특정 교재·저자·기관 인신공격
- 출처 없는 "실무는 이런 것" 식 주장

## 로컬 개발

```bash
npm ci
npm start            # http://localhost:3000
npm run build        # 빌드 검증
```
