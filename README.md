# DB is Middleware

> "DBMS는 대표적인 미들웨어의 하나이다." — 2020년대에도 현역인 정처기 수험서의 한 구절

**정보처리기사 시험**을 준비하면서 발견한
- 시대착오적이거나
- 사실과 다르거나
- 실무와 동떨어진

서술을 **현직 개발자 관점으로 팩트체크**하는 오픈 아카이브입니다.

사이트: <https://broccolism.github.io/db-is-middleware/>

## 글 구조

각 팩트체크는 다음 4섹션을 따릅니다.

1. 📌 **3줄 요약 (TL;DR)** — 시험/실무/결론
2. 🧠 **구체적이고 효과적인 답변** — 역사적 맥락 + 정리
3. 🎯 **정처기 문제 풀 때 꿀팁** — 키워드 매칭 + 함정 주의
4. 🛠️ **실무 팩트 체크** — 2026년 기준 현업 용법

템플릿: [`blog/_template.md`](./blog/_template.md)

## 이 레포가 하지 않는 일

- 정처기 무용론
- 특정 교재·저자·기관 인신공격
- 출처 없는 "실무는 이런 것" 식 주장

## 로컬 개발

```bash
npm ci
npm start            # http://localhost:3000
npm run build        # 빌드 검증
```
